# Royal House

Сайт жилого дома в Калининграде: фотоистория строительства по годам, подбор планировок и информация о доме.

[Открыть сайт](https://dvigaitelom1234-byte.github.io/royal-house/).

Статический HTML, CSS и JavaScript. Фотографии, планировки и шрифты хранятся в репозитории. Серверная сборка не требуется. Отправка формы в отдел продаж пока не подключена.

## Локальный запуск

Из корня репозитория создайте локальное окружение:

```sh
python3 -m venv venv
venv/bin/python -B -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Для проверки интерфейса нужен установленный Google Chrome:

```sh
venv/bin/python -m pip install -r requirements.txt
venv/bin/python -B pipeline.py
```

Пайплайн обновляет версии ресурсов, проверяет фотоархив и интерфейс на пяти размерах экрана, включая фильтры, листалки, модальные окна и форму. Временные файлы создаются внутри проекта.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Перед коммитом изменений запускайте пайплайн; после пуша GitHub автоматически обновит сайт.
